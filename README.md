# E-Commerce-Customer-Churn-Prediction
In e-commerce businesses, customers often stop buying products or abandon their accounts after a while (this is called customer churn). It is hard to know when a customer is about to leave before they stop using the site completely.
Finding new customers costs much more money than keeping existing ones. If we can use Python and data science to predict which users are likely to churn, the marketing team can give them special offers or discounts to keep them using the platform.
